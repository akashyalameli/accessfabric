# AuthBridge

Enterprise Identity Federation & Authentication Platform

## Overview

AuthBridge is a modular authentication and federation platform inspired by enterprise IAM systems.

Core capabilities:

- Multi-tenant identity management
- JWT authentication
- Refresh token rotation
- MFA (TOTP)
- SAML federation
- RBAC
- Audit trails
- Authentication flow visualization

## Architecture

Modular monolith designed for future service extraction.
